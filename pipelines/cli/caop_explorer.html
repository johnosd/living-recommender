Explorador da CAOP

Esta é a base territorial que o projeto construiu. Uma linha em municípios identifica um município; várias linhas em freguesias apontam para ele pelo código dico.

1. RawZIPs originais da DGT, sem alterações.
2. BronzeGeometria e códigos preparados para validação.
3. SilverTabelas simples para consultar e juntar a outras fontes.
