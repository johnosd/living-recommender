# Memória de longo prazo do projeto

Esta pasta guarda conhecimento durável deste repositório entre tarefas e
sessões. Antes de tomar decisões ou executar uma skill SDD, consulte as notas
Markdown relevantes ao contexto. Durante o desenvolvimento, registre novos
insights importantes para trabalhos futuros em arquivos `.md` concisos, com
data, contexto e evidências ou referências verificáveis. Identifique hipóteses
e limitações; não inclua segredos nem dados sensíveis.

`constitution.md` contém a constitution do projeto e continua sendo o gate
formal exigido pelos fluxos SDD. As outras notas apoiam o trabalho, mas não
substituem a constitution nem modificam decisões aprovadas. Decisões
arquiteturais formais continuam em `.sdd/adr/`.
